# KK Music Land

**Student:** David  
**Module:** Programming (Minor CDT)

## Description
A rhythm game in Processing where colorful notes fall to the beat of music. Click notes before they reach the bottom to score points. Features include a main menu, game over screen, and restart functionality.

## Features
- ✓ Custom vector graphics (notes and buttons)
- ✓ Automatic note movement with beat detection
- ✓ Object-oriented design (`Note`, `Button`, `GameManager`, etc.)
- ✓ Mouse and keyboard input
- ✓ ArrayList for managing multiple notes
- ✓ Sound library integration with FFT analysis
- ✓ Weather API integration for dynamic backgrounds

## How to Run
1. Open the sketch folder in Processing
2. Install the Sound library (Sketch → Import Library → Add Library → Sound)
3. Ensure audio file exists in `data/gamemusic/`
4. Run and press Start or Enter to play
